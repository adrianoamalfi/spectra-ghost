Spectra

A Ghost theme that colours itself from one accent. Modern, flexible and accessible, for personal sites.

This page is built with the theme's own colour model: change the accent and every surface, ink and fill re-derives, in light and dark.

Four heroes, one set of rules

Every hero is built from your real content: title, description, topics, counts, featured post and the publication cover. Pick one in Ghost Admin.

A feed that adapts to its tiles

Tiles are CSS containers. Headings change size, width and weight with the width of their own tile, so the same card works as a feature or as a small entry. Bento is the default; Grid and List are one setting away. Infinite scroll keeps the pagination links in place.

A featured slider, when you want one

Turn on show_featured_slider and the featured posts that the hero does not already show become a swipeable row. The feed skips them on the first page, so nothing appears twice.

A calm place to read

Choose an article shape in Ghost: Essay gives long-form work room to breathe; Note keeps shorter writing close to the reading column. Both keep the same reading tools and accessible controls.

Everything that helps a long read

  • Table of contents with scroll-spy, collapsed on small screens
  • Heading anchors that copy the section link
  • Copy button on code blocks, scrollable tables
  • Image lightbox on a native dialog, with arrow keys
  • Reading progress, previous and next post, related posts
  • Comments loaded only when the reader scrolls near them

Share, support, continue

The share row offers X, Facebook and a copy-link button, the same accounts Ghost has in Social accounts. With donations on it also carries a support button.

Gated posts, one clear call to action

Ghost adds its own upgrade box to locked posts. Spectra replaces it with a single one, worded for free or paid access, so readers never see two.

Pages, footers and phones

Four page templates, two footers and a header that turns into a menu on small screens.

Install

Spectra needs Ghost 6.0 or newer (tested with Ghost 6.69) and a current browser: Chrome and Edge 123+, Safari 17.5+, Firefox 128+.

  1. Get the theme. Download spectra.zip from the Releases page, or build it with npm run zip.

  2. Upload it. In Ghost Admin open Settings, Design & branding, Change theme, Upload theme, then activate it.

  3. Choose your look. Open Design to pick the hero, footer and feed styles. Set your accent colour under Brand and your cover under Settings, General.

  4. Add the page templates you need. In the page settings pick Landing, Archive, Membership or Newsletter.

Languages

English, Italian, German, Spanish, French, Portuguese and Dutch. Spectra reads Ghost's site language. To add one, copy locales/en.json, translate the values and run npm run check:i18n.

Footer and social

Both footers use the secondary navigation, the X and Facebook accounts set in Ghost, RSS, Ghost recommendations and the donations button.

Visitors can override the colour scheme with the switch in the header; their choice is saved in their browser and wins over color_scheme. The header logo keeps its uploaded colours in Light mode and becomes monochrome white in Dark mode; Auto follows the visitor's system preference.

One colour in, a whole palette out

Spectra reads the accent from Ghost Admin and derives everything else in OKLCH, for light and dark. You are looking at it now: use the accent picker at the top of the page.

TokenRole
--accentThe accent from Ghost Admin
--color-bg, --color-surfacePage and tile surfaces, tinted by the accent hue
--color-fg, --color-mutedInk and secondary ink
--accent-inkAccent as text or a line, lightened or darkened per scheme
--accent-fill, --color-on-accentA solid fill that always carries AA text, and the ink on it
--accent-2Secondary accent, for text selection and link underlines
bg surface tile tint fill ink

Accessibility, measured

  • Across 98 accents spanning the whole colour wheel, in both schemes, the lowest contrast of a fill and its text is 4.54:1. Normal text is between 12:1 and 17:1.
  • Koenig cards that Ghost paints with the raw accent are remapped to the same fill, with no contrast errors in the axe-core check.
  • axe-core reports no violations in the theme's templates on the home, archive, membership, tag, author, 404 and article pages that were tested, in light and dark.
  • Motion is limited to short transitions and respects prefers-reduced-motion.
  • Everything works without JavaScript except the documented enhancements.

The full set of design rules is in DESIGN.md.

Develop

Plain CSS and a little progressive JavaScript. No build step, no framework.

npm ci
npm run check   # gscan, translations, static accessibility
npm run zip     # spectra.zip, ready to upload

Pull requests run CI, which validates the theme and ZIP. A matching vX.Y.Z tag publishes a GitHub Release. See CONTRIBUTING.md for the release process and branch protection guidance.

Link the folder into a local Ghost install and restart Ghost: ln -s "$PWD" /path/to/ghost/content/themes/spectra. CSS and JavaScript changes show after a reload; templates and settings need a restart.
